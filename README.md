# Dombra Tuner

Онлайн-тюнер для казахской домбры. Работает прямо в браузере: слушает открытую струну через микрофон, определяет высоту звука и показывает, нужно подтянуть или ослабить струну.

## Возможности

- распознавание высоты звука в реальном времени;
- пять традиционных типов строя: оң, теріс, қалыс, шалыс и тел бұрау;
- звуковой эталон для каждой струны;
- интерфейс на русском и казахском;
- локальная обработка без отправки аудио на сервер;
- адаптивная версия для телефона.

## Локальный запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Для Vercel используется отдельная Next.js-сборка:

```bash
npm run build:vercel
```

Конфигурация в `vercel.json` выбирает её автоматически. Основная команда `build` сохранена для Cloudflare/Sites-версии проекта.

## Open source

Определение высоты звука построено на [Pitchy](https://github.com/ianprime0509/pitchy) — реализации McLeod Pitch Method под лицензией MIT. Захват и синтез эталонного звука работают через стандартный Web Audio API.

Справочная часть о типах строя подготовлена по материалам Казахского национального университета искусств и культурных ресурсов Казахстана. Абсолютная высота традиционного строя может зависеть от инструмента, голоса и исполнительской школы.
